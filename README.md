# PflegeCloud Lab

**Pflegefachmann auf dem Weg in die Cloud-Security**

Vom Pflegefachmann zum Cloud Engineer: Hier dokumentiere ich meinen Weg in die IT.

## Ziel
Eine sichere Azure-Infrastruktur für eine fiktive Krankenhausstation, nur mit erfundenen Daten.

## Roadmap
- [ ] AZ-900 (Azure Fundamentals)
- [ ] SC-900 (Security Fundamentals)
- [ ] CCNA (Cisco Certified Network Associate)
- [ ] AZ-104 (Azure Administrator)
- [ ] AZ-500 (Azure Security Engineer)
- [ ] Generative KI: sicherer KI-Assistent für die Pflegedokumentation (Azure OpenAI, nur fiktive Daten)

## Lernprotokoll
### Woche 1: Netzwerk-Grundlagen
- Ubuntu in einer virtuellen Maschine installiert
- `ip a`: IP-Adresse (wie eine Zimmernummer) und MAC-Adresse (wie ein Patientenarmband)
